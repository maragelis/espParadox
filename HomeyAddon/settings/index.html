Paradox SP/MG Bridge

Connection used by every Paradox area and zone device. Leave the address empty to find the bridge automatically on your network (mDNS).

How to
1. Get started
  1. The ESP32 bridge must be connected to the panel's serial port and to your WiFi. Open its web page (its IP address in a browser) and check that the panel shows online.
  2. Below, enter the bridge's web user and web password (the login of its web page). Leave Bridge address empty - the bridge is found automatically. Press Test connection, then Save.
  3. Status should say Connected to bridge … Panel: online.
2. Add your alarm areas and zones
  1. Homey: Devices → + → Paradox SP/MG Bridge → Alarm area. Pick the area(s). Each area can be armed / disarmed from its tile.
  2. Then Alarm zone: pick the zones you want as sensors.
  3. Zone names, which zones exist and whether a zone is a contact or motion sensor are set on the bridge's web page: Settings → Zones. Changes there show up in Homey by themselves.
3. Arm and disarm
  • Alarm tile (Homey's home alarm): armed = Full arm, partially armed = Stay or Sleep (choose in the area's device settings), disarmed.
  • Alarm mode picker: the panel's own Disarmed / Stay / Sleep / Full.
  • An area can't arm while a zone is open - check Ready to arm first.
4. Flow ideas
  • Arm when everybody leaves: WHEN Someone left home AND Everybody is away → THEN Set alarm mode to Full arm as [Name].
  • Disarm on arrival: WHEN Someone came home → THEN Set alarm mode to Disarm as [Name].
  • Alarm notification: WHEN Alarm turned on (area) → THEN send a push notification / turn on lights.
  • Door left open: WHEN a contact zone opens AND the area is armed → THEN notify.
  • Power cut: WHEN Paradox panel lost AC power → THEN notify.
  • Battery: WHEN Paradox panel battery became low → THEN remind me to replace it.
  • Anything else: WHEN A Paradox panel event was received gives the event text, group, area and time.

Use Set alarm mode … as [who] with the Name tag so the timeline shows the person. Homey doesn't tell apps who tapped a tile, so taps show as "by Homey".

5. Timeline

Every arm, disarm, alarm, AC power and panel battery change is added to the Homey timeline with who did it: the panel user's name (keypad / remote), keyswitch, auto-arm, Homey, or the bridge's web page / MQTT. Panel user names come from the panel's user labels. Switch it off below under Timeline.

6. Troubleshooting
  • No bridge found: the bridge needs firmware 1.6.9 or later. A self-hosted Homey in Docker needs host networking for automatic discovery - or type the bridge's IP address (reserve it on your router).
  • Wrong bridge user or password: use the login of the bridge's web page.
  • Devices unavailable "Panel disconnected": the panel link is down or was disconnected on the bridge's web page (press Connect panel there).
  • A zone is unavailable: it's set to Never on the bridge's Settings → Zones page.
  • Arming fails: the area isn't ready (a zone is open) or the panel refused it - the bridge's web page shows the last action result.
