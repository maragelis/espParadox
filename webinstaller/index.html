Paradox SP/MG Bridge

Install the bridge firmware on an ESP32 straight from your browser. No tools to install.

1. Choose your board

2. Connect and install

Plug the board in with a USB data cable, press Install and pick its port.

Your browser can't reach USB devices. Use Chrome or Edge on a computer (not a phone or Safari/Firefox).
The installer needs a secure (https) page. Open it from its GitHub Pages address.
Firmware version @VERSION@

Good to know

  1. Updating an existing bridge? Leave Erase device unticked and your settings are kept. Tick it for a completely fresh start.
  2. Port not listed? Install the USB driver for the board's chip (CP210x or CH340/CH9102), then reload this page.
  3. "Failed to connect"? Hold the board's BOOT button, tap EN/RST, release BOOT, and press Install again.
  4. After installing: join the WiFi ParadoxBridge (password paradox123), open http://192.168.4.1, log in with admin / changeme, set up your WiFi and change the password.
  5. Later updates also work over WiFi: download firmware.bin for your board and upload it on the bridge's Settings → System → Firmware update.
